# 视频 Prompt 内容合同

## 固定章节

每份 `video-prompt.md` 必须包含且仅使用以下二级标题作为骨架：

1. 视频目标
2. 全局视觉风格
3. 角色和参考素材
4. 完整故事
5. 精确时间轴
6. 分镜与时间轴
7. 连续性要求
8. 负面约束
9. 结尾状态

`分镜与时间轴` 下的每个三级标题必须是 `### MM:SS-MM:SS`。每段都必须含以下标签（冒号后的内容不可为空）：

- `场景：`
- `角色：`
- `画面构图：`
- `角色动作：`
- `摄影机运动：`
- `对白和旁白：`
- `连续性要求：`

## 时间规则

- 第一个分镜从 `00:00` 开始，后续分镜起点等于上一段终点。
- 每段终点必须大于起点，最后一段终点与“视频目标”中声明的总时长一致。
- “精确时间轴”必须有一张表格，列出与分镜相同的时间段和叙事目的。

## 可生产性的最低要求

- 视频目标包含受众、时长、核心理解或情感结果。
- 全局视觉风格说明媒介、光线、色彩、画幅/构图倾向和文字呈现原则。
- 角色和参考素材说明每名跨镜角色的外观锚点，且只引用已存在资料或明确标识“无外部素材”。
- 完整故事给出开端、误解或张力、解释、结果与收束。
- 连续性要求覆盖角色外观、空间方向、道具/数值、光线或色彩及音画衔接。
- 负面约束至少列出五项，包含事实、角色或文字、视觉稳定性、情绪尺度与无关元素。
- 结尾状态说清最终画面、最后一句音频（如有）以及观众应带走的结论。

## 不确定信息

使用 `待确认：<问题>` 标记不能由 brief 或系列资料支持的信息。不得伪造研究数据、文件、品牌合作、肖像授权或模型能力。
