# 项目背景与资料边界

## 项目是什么

这是一个由 Codex harness 在本地执行的 Markdown 生产流程。目标是把单集创作输入转为可制作的 AI 视频 Prompt，固定输出为：

```text
outputs/<episode-id>/video-prompt.md
```

项目不需要，也不应引入 Codex SDK、Agents API、网页、数据库、视频模型适配器或视频生成 API。

## 全局叙事背景

所有视频默认发生在《海绵宝宝》的比奇堡，以熟悉的角色和地点把经济学概念变成具体的生活选择、经营决策或市场变化。完整的世界观、角色视觉锚点和选角规则见 [比奇堡世界观与角色选角](bikini-bottom-setting.md)。

这是一套非官方的教育性二创叙事设定：不得暗示作品获得官方授权、使用原剧片段，或把角色言行说成原作中的既定情节。

## 资料优先级

当资料互相冲突时，按以下顺序决定：

1. 用户在当前任务中的明确要求。
2. `episodes/<episode-id>/brief.md` 的本集事实和交付约束。
3. `series/<series-id>/` 的跨集角色、世界观和视觉连续性。
4. 本目录中的通用规则和模板。

没有被上述资料支持的事实、外部素材、授权、品牌、数字或模型能力，必须写为 `待确认：<问题>`，不得当作既定事实。

## 目录职责

| 位置 | 保存内容 | 不保存内容 |
| --- | --- | --- |
| `.doc/` | 稳定规则、背景、流程、模板 | 单集成片 Prompt 或具体创作事实副本 |
| `.agents/skills/` | 任务发现和阅读路由 | 规则、模板或背景正文副本 |
| `series/` | 可复用的系列事实资料 | 通用工作流程 |
| `episodes/` | 单集事实输入与禁用项 | 生成后的 Prompt |
| `outputs/` | 唯一交付物 | 草稿、脚本或输入资料 |
| `scripts/` | 确定性校验工具 | 创意、事实判断或视频生成调用 |
