# 故事情节与类比机制

## 目标

每集都用一个**角色想完成的具体目标**承载一个经济关系：观众先看见角色遇到的压力、作出的直觉判断和随后的结果，再得到概念名称与克制的现实迁移结论。类比不是把术语换成角色名称；它必须保留概念中真正起作用的关系，并让这个关系能被画面、动作和短句同时看见。故事题材可以是任意的，选择它的第一标准是能否准确反映主题，第二标准才是题材与场景。

## 先设计，再写 Prompt

在写“完整故事”和分镜前，先在草稿中完成以下故事卡；故事卡是生成过程中的检查项，不写入最终 `video-prompt.md`：

| 项目 | 要回答的问题 | 合格示例形式 |
| --- | --- | --- |
| 主角目标 | 主角现在必须完成什么具体目标？ | 用一枚贝币买午餐、赶上一次培训、在开演前带团队完成合唱 |
| 可见阻碍 | 什么东西变化了，什么关键条件没有变？ | 来买的人和贝币变多，但午餐仍只有 6 个蟹黄堡 |
| 直觉误解 | 主角或观众最可能怎样误读？ | “钱变多，午餐应该更轻松” |
| 类比映射 | 每个抽象要素分别由什么物件、行动或关系承担？ | 货币—贝币；商品供给—6 个蟹黄堡；购买力—一枚贝币实际能换到的份量 |
| 纠正动作 | 哪个可重复观察、比较或小实验让误解自行失效？ | 数清 6 个蟹黄堡、翻转价格牌、在透明板上连线 |
| 迁移边界 | 这个例子解释了什么，又不能替代什么？ | 说明简化情境中的购买力变化，不说明现实通胀的全部成因 |

没有清楚的“变化—未变化—结果”链条时，不要用旁白直接宣布结论；先重选一个更能让角色行动、并准确承载主题关系的场景。

## 五拍情节引擎

一个完整故事按以下节拍推进。时长可按概念复杂度伸缩，但不得跳过理解所需的拍子。

1. **目标与常态**：用一个具体交换、选择或任务开场，让观众在几秒内知道角色想要什么，以及原来怎样顺利完成。
2. **变化与张力**：只改变当前概念所需的一两个条件，并让压力变得可见，例如时间在流逝、队友在等待、名额在减少或原计划将被打断。让角色先作出一个自然、但不完整的判断；困惑是学习入口，不能成为羞辱笑料。
3. **约束显形**：用可数物件、队列、账本、时间、比较卡或空间位置，把没有随之改变的关键约束放进画面。
4. **行动验证与命名**：让角色数、换、比、记、排或试一次，亲眼看到结果；随后由角色或旁白用一句白话解释，最后才给出术语和公式（如有）。
5. **回扣与边界**：角色带着新理解完成或调整原目标，结尾用一句能迁移到现实的记忆句收束，同时说明这个比奇堡例子不等于现实中的完整因果或行动建议。

每个拍子至少要推动一个“故事动作”或“理解动作”。例如，派大星把贝币推向柜台是故事动作，观众看见 6 个蟹黄堡仍固定不变是理解动作；两者都不能只由旁白替代。

## 类比映射规则

- 选择角色的日常目标时，优先使用购买、排队、制作、记账、比较、训练、协商、试验等自然动作；不要让角色无缘无故站在镜头前听课。
- 类比中的数量、方向和因果必须一一可追踪。若要解释“价格 ÷ 每股收益”，就分别展示价格、每股收益和除法过程，不能用一个模糊的“赚得多”图标代替。
- 一个故事只承载一个核心关系。需要对照时，最多改变一个变量，其余条件留在画面中，帮助观众看出什么导致了差异。
- 用角色之间真实的视角差异制造张力：消费者想买到东西、员工面对产能、经营者面对约束、学习者想读懂数字。任何一方都不是预设反派。
- 类比必须在结尾标出边界。使用“在这个简化场景中”“这说明的是……，不代表……”等自然表述，避免把故事结果说成现实世界的唯一原因、必然结果或投资结论。

## 创造性与类比距离

类比的价值来自“因果相同、世界不同”。把“股票”改名为“练习股”、把“公司”改名为“海底公司”，仍然是术语换皮，既缺少想象力，也无法给观众新的理解入口。除非本集必须逐步演示公式或 brief 明确要求金融场景，否则把抽象概念放进与原术语明显不同、角色能真心投入的简单故事中；生活化场景是常用选择，但不能优先于主题映射的准确性。

在故事卡之后，先用一句话草拟至少两个候选世界，再选择最适合拍摄的一个。例如，FOMO 可以是“公交站里跟着人群改乘一辆车”或“街市里想抢大家都在拿的点心”，关键不在物件名称，而在“人群热度与紧迫感上升，却没有增加角色对目标、风险或条件的理解”。选定时遵守以下规则：

- **因果骨架先行**：先写出不可替换的关系，再换世界。例：可见热度上升 → 主角担心落后 → 冲动改变原计划 → 核对后发现热度没有回答“是否适合自己”。
- **去术语测试**：删掉概念名、行业名和结尾解释后，故事仍应是一段可成立的比奇堡小故事；若剩下的只是课堂、卡片和定义，必须重选场景。
- **双重可见性**：每个隐喻元素都要既服务故事目标，也服务概念映射。潮流贝壳既是珍珍夜游时可能换上的灯，也是“被热度推动的选择”；不能只是背景装饰。
- **让生活制造转折**：从地点的日常规则、角色习惯、道具功能和小任务中产生转折，例如等车、做饭、买菜、排队、上班、课堂、后厨或街市；不要为了显得有想象力而强行加入冒险、奇观或复杂设定。
- **最后才回扣主题**：主体故事最多只出现本世界的目标和规则；用结尾的一两句把它映射回经济概念，并明确类比不等于现实中的完整判断或行动建议。

## 主题映射优先，生活化是默认素材

故事不必是冒险、比赛、危机或大场面，也不必被限制在生活片段。优先级固定为：**主题关系准确 → 主角有代价的选择 → 画面简单可见 → 场景贴近生活（如适合）**。赶车、做饭、挑礼物、买菜、排队、完成作业等日常片段通常易懂；但只要其他故事更准确、更有张力地保留主题关系，就应选择它，而不是为了“生活化”硬套一个平淡场景。

- 开场十秒内让观众知道“角色现在要做什么、若跟错会失去什么”，不先介绍设定、规则或角色背景。
- 一个故事只保留一个目标、一个变化、一个误解和一个验证动作；不要用支线、反转、多个新道具或多个问题增加理解负担。
- 让类比落在看得见的东西上：公交路线、购物清单、锅里的份量、排队位置、钟表、门票或便签。观众应先看懂物件关系，再听懂概念。
- 叙述优先用短句和日常动词，例如“她赶着去图书馆”“大家都上了那辆车”“她先看路线图”，而不是抽象解释、角色履历或复杂世界规则。

## 张力与观看动力

张力不等于危险、争吵或复杂反转。它来自角色必须在有限时间里做出一个会影响当前目标的选择。每个故事在前三秒就应展示一个未解问题，并在中段让观众关心“她会不会做错”。

- **目标要值得守住**：它可以很小，但必须和角色或团队有直接关系，例如赶上闭馆、保住一顿饭、完成约定、带队上台或不让同伴白练。
- **压力要看得见**：用舞台开幕、倒数钟、正在移动的队伍、即将离开的车、等待的队友或一项已经开始的任务呈现；不用旁白空喊“很紧急”。
- **选择必须真实**：热门选项可以对别人合理，原计划也不是天然正确。主角真正需要判断的是“它是否适合我此刻的目标和条件”。
- **验证带来转折**：让主角试一次、比一次、对照一次或问一个关键问题，使原先的直觉自己站不住，而不是由权威直接否定。
- **收束兑现开场**：结尾必须回答最初的问题，并让观众看到主角或团队因新理解完成、调整或放弃了什么具体行动。

## 通俗、生动的讲述规则

- **先看见，再命名**：先展示“6 个蟹黄堡没变、来买的人更多”，再说“供给”“购买力”；术语第一次出现时，紧跟一个正在发生的动作或屏幕短句。
- **一句只讲一个关系**：对白优先使用主语、动作和结果，例如“同样一枚贝币，现在只能换半个”，不要连续堆叠定义、例外或多个新名词。
- **让物件承担解释**：数字用大字号卡片、透明板或可数道具呈现；情绪用停顿、视线、手势和小目标受阻表现，不用夸张哭喊或灾难化画面。
- **让喜剧服务理解**：可以有温和的意外、节奏错位或角色反应，但笑点只能来自情境，不来自无知、贫困、经营者或任何群体的被贬低。
- **每次解释都回到目标**：说完机制后，立刻回答它怎样改变了主角原本想做的事；如果删掉该段仍不影响主角选择，说明它是无关讲解，应删除或改写。

## 交付前的叙事自检

- 观众不听旁白，只看角色和道具，能否猜到发生了什么变化？
- 观众只听对白和旁白，能否复述“什么变了、什么没变、结果为何出现”？
- 是否有一个真实但不完整的直觉误解，并由角色行动而非权威宣告来纠正？
- 概念、数字或公式是否都对应一个可见物件或动作，且没有跳过必要中间步骤？
- 最后一处结论是否回扣主角的目标，并保留现实复杂性和本集禁止项要求的边界？
- 删除概念名和行业名后，这是否仍是一段有目标、阻碍、转折和收束的比奇堡故事，而不是换了名词的课堂讲义？
- 能否用一条简单映射说清：故事里的“热度、压力、冲动选择、关键条件、验证结果”各自对应主题中的什么？若有任何一项说不清，先修类比，不靠增加设定或旁白补救。

校验脚本只检查结构与时间；以上项目需要在生成时进行人工语义审核。
