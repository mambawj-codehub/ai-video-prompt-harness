# 视频 Prompt 生成规则

## 固定内容合同

每份 `video-prompt.md` 必须使用以下二级标题，且内容不可为空：

1. 视频目标
2. 全局视觉风格
3. 角色和参考素材
4. 完整故事
5. 精确时间轴
6. 分镜与时间轴
7. 连续性要求
8. 负面约束
9. 结尾状态

`分镜与时间轴` 下，每个三级标题均为 `### MM:SS-MM:SS`，并且每段都有非空的：场景、角色、画面构图、角色动作、摄影机运动、对白和旁白、连续性要求。

## 时间与叙事

- 单集时长按概念复杂度和讲清所需信息决定，不固定为 60 秒，且必须大于 0、不得超过 150 秒。
- 首段从 `00:00` 开始；后一段起点必须等于前一段终点；最终终点等于“视频目标”声明的总时长。
- “精确时间轴”用表格列出与分镜完全相同的时间段、叙事目的、关键信息和声音重点。
- “完整故事”必须交代开端、张力或误解、解释、结果和收束；分镜把这些内容落实为可拍摄、可剪辑的具体画面。
- 每个故事必须让一个具体角色目标承载一个核心经济关系，并呈现“什么变了、什么没有变、因此出现什么结果”。概念名称、公式或定义必须在对应关系已被角色行动和道具展示后才出现。
- 主题映射的准确性优先于故事题材是否生活化或是否新奇。每个故事都必须有可见压力下的真实选择，以及由核对、比较、试验或提问带来的转折；不得只用平淡场景或旁白复述概念。
- 不得用“虚构练习股”“海底公司”等方式机械替换概念名来充当类比；除非 brief 要求金融场景或公式演示，主体故事应选用因果相同但世界明显不同、简单可见的场景，最后再回扣概念。生活化优先于复杂设定，但不能优先于主题映射的准确性；故事题材不预设为冒险。
- 类比的设计、五拍节奏、通俗表达与交付前自检，统一遵循[故事情节与类比机制](storytelling-mechanism.md)。它是语义质量合同；结构校验不替代该合同。

## 比奇堡选角规则

- 每集默认在比奇堡发生，并先阅读 [比奇堡世界观与角色选角](bikini-bottom-setting.md)。
- 先从经济关系选择角色功能，再选择角色：例如消费者、经营者、前台员工、熟练白领、学生、创业者或路人市场参与者。
- 角色的经济身份服务当集概念，不能当作永久身份或道德评价。尤其不能把蟹老板、痞老板等角色直接写成“坏资本家”或把普通角色写成应为经济结果负责的一方。
- 保持角色外观、行为习惯和地点锚点可辨认；不复刻原剧具体台词、剧情、镜头或片段。

## 可生产性

- 视频目标要包含受众、总时长、观看结果和核心问题；不要为了压缩时长而删掉概念成立所必需的机制、误解澄清或结论边界。
- 全局视觉风格要明确媒介/质感、光线/色彩、画幅/构图、屏幕文字和音乐/声景。
- 角色和参考素材要列出跨镜外观或声音锚点，并只引用仓库已有路径或说明“无外部素材，按本系列原创设定制作”。
- 角色和参考素材必须标明本集经济功能，以及该功能为何适合当前概念。
- 连续性要求覆盖角色外观、空间方向、关键道具或数值、光色与音画衔接。
- 负面约束至少五条，覆盖事实误导、角色或文字一致性、视觉稳定性、情绪尺度和无关元素。
- 结尾状态要说明最终画面、最后一句音频（如有）和观众应带走的结论。

## 不确定信息与校验边界

使用 `待确认：<问题>` 标记资料未支持的信息。校验脚本只确认文件结构和时间结构；它不证明事实、因果、视觉质量、角色还原度、版权状态或视频模型实际表现。
