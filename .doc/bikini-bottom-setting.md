# 比奇堡世界观与角色选角

## 用途与边界

本文件是所有视频的默认叙事背景。用比奇堡的地点、角色关系和喜剧气质降低经济学理解门槛：先让观众看到一个熟悉角色遇到的生活或经营问题，再解释背后的经济机制。

它用于原创教育性二创 Prompt，不是原剧剧情库。不得声称官方合作、授权或原作发生过本项目编写的事件；不得要求复制原剧片段、镜头或台词。

## 世界观锚点

- 地点：比奇堡及其日常空间，例如蟹堡王、海之霸、菠萝屋、石头屋、章鱼哥的房子、珊迪树屋、驾校和海底街市。
- 气质：明亮、夸张但友好；喜剧来自角色面对经济关系时的反应，而非羞辱、恐吓或把经济后果归咎于某个人。
- 表达：每次只让一个可见的关系成为焦点，例如“贝币数量—蟹黄堡数量—价格”或“利润—成本—经营选择”。术语出现后立即用角色的行动、物件或短句解释。
- 视觉：使用原创的高品质 3D 卡通海底画面表现比奇堡氛围；不使用原剧截图、片段或逐帧复刻。

## 选角步骤

1. 写出本集要展示的经济关系与参与者，而不是先挑最热门的角色。
2. 从上表选择能让该关系自然可见的角色；一集通常 2 至 4 名有台词角色即可。
3. 在“角色和参考素材”章节写清每个角色的本集经济功能和外观/声音锚点。
4. 在每段分镜中让角色通过购买、制作、比较、记账、协商、学习或观察来推动解释。
5. 若概念需要多种视角，使用角色之间的真实利益差异，避免将任何一方塑造成结论预设的反派。

## 跨集连续性

- 同一角色在一集内保持可辨认外观、音色、情绪尺度和空间方向；关键价格、数量和道具从出现到结尾保持可追踪。
- 经济学结论要克制：用“可能”“在这个简化场景中”等表述区分比奇堡例子与现实复杂经济。
- 所有屏幕文字使用简体中文、短句与大字号；不添加现实品牌、投资建议、真实统计数据或未经提供的外部素材。
